# Time Cycles (StoneFace)

Pine Script v6 indicator for drawing session-based time cycles:
- Sessions: Asia (20:00–00:00), London (02:30–07:00), NY AM (07:00–11:30), NY PM (11:30–16:00)
- 90-minute cycles (3 per session) and 30-minute cycles (9 per session)
- Optional NY midnight price line
- Configurable colors, transparency, and timeframe limits

Main file: `time-cycles.pine`

## Quick Start
1. Copy `time-cycles.pine` into TradingView Pine Editor.
2. Save and add to chart.
3. Adjust inputs as desired.
