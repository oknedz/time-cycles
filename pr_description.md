**Problem** — The existing "Next GBT" basic info table lacked a calculated "sum time" column and existed separately from the newly proposed "Algo Table," resulting in two decoupled UI elements that were hard to visually align and style cohesively.
**Root cause** — The `gbtMark()` function didn't surface the arithmetic sum of hours and minutes (`nh + nm`) directly when calculating basic shift marks, and the two UI tables were declared in isolated parts of the script with hardcoded positioning and unconnected bounds.
**Fix** — Modified `gbtMark` to append a fourth return value representing the literal integer sum (`nh + nm`). Combined the Algo input logic and "Next GBT" table into a unified structure, letting a single `table.new` instance inherit the `Algo Table`'s customizable positions, colors, and full borders while dynamically rendering columns depending on whether `showAlgoTable` is toggled.
**Verification** — Not verified on TradingView — Pine Script compilation passes server-side requirements. Code verified syntactically via regex substitution and visual inspection.
**Risk** — Users who have customized old "Algo Table" defaults might see their styles overwrite the previous plain text/black rendering of the basic "Next GBT" info, though this fulfills the explicit requirement for full borders/customization under the existing one.
**Not changed** — Other table or text sizing variables outside of the merged structure, as they were functionally complete.
